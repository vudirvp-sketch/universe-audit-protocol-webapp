# Безопасность и обращение с ключом API

У проекта нет бэкенда: статическая страница обращается к API провайдера напрямую. Значит, ключ
не проходит ни через один сервер проекта — но и защищать его приходится на стороне браузера.
Этот документ честно описывает, где ключ лежит, куда ходит и чего эта схема не покрывает.

## Где живёт ключ

| Режим | Где хранится | Переживает перезагрузку | Переживает закрытие вкладки |
|-------|--------------|-------------------------|-----------------------------|
| По умолчанию | `localStorage`, ключ `universe-audit-settings` | да | да |
| «Не сохранять ключ на диск» | `sessionStorage`; в `localStorage` пишется `apiKey: null` | да | нет |
| Relay с env-ключом | переменная окружения процесса relay | — | — |

По умолчанию ключ лежит в `localStorage` открытым текстом. Это осознанный компромисс ради
удобства: любой, у кого есть доступ к профилю браузера, к полному бэкапу диска или расширение
с правами на хост, может его прочитать.

## Куда ходит ключ

- **Напрямую из браузера.** Браузер → провайдер. Единственный посредник — собственный код
  приложения. Ключ уходит в заголовке: `x-goog-api-key` для Gemini, `x-api-key` для Anthropic,
  `Bearer` для остальных.
- **Через локальный relay.** Браузер → `127.0.0.1:8787` → провайдер. Ключ пересекает только
  петлевой интерфейс, а при `LLM_API_KEY` вообще не попадает в браузер. Клиент проверяет
  URL relay (https, либо обычный http только для петлевого адреса) и базовый URL провайдера
  до того, как что-либо отправить.

## Остаточные риски

- Вредоносное расширение браузера, скомпрометированная зависимость или доступ к профилю браузера
  всё ещё могут прочитать сохранённый ключ. Против этого инструмент предлагает два средства:
  режим «только на сеанс» и env-ключ relay.
- Внедрённый в вывод модели текст не может выкрасть ключ: HTML отчёта экранируется,
  сырой HTML из модели не включается.
- Relay — локальный инструмент разработчика: любой процесс того же пользователя на этой машине
  может к нему обратиться, а ключ, переданный в теле запроса, идёт по петлевому интерфейсу
  открытым текстом. Запускайте на доверенной рабочей станции.

Подробности модели угроз relay — в [`../relay/README.md`](../relay/README.md).
